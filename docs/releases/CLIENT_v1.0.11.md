# Windows Client v1.0.11

- 控制平面请求明确关闭 HTTP/1.1 连接，避免服务端已关闭连接仍被复用并触发额外超时重试。
- EasyTier 网络和服务器路径已通过静默快检时，启动游戏前跳过重复的 PowerShell 路由绑定，减少点击“启动游戏”后的等待。
- 配合新版控制平面，单人创建房间后启动器可显示本机房主状态；房主信息仍只采用服务端权威数据。
- Route Guard 版本同步为 v1.0.11，严格进程授权、心跳超时 fail-open 和游戏运行期间网络保护策略不变。

本版本不恢复本地房主猜测、广播转换或单播扇出，也不会在游戏运行时重启 EasyTier 或重建虚拟网卡。
