# Windows Client v1.0.12

- 房主状态栏不再显示玩家数量，改为直接显示当前角色、延时和 EasyTier 实际底层线路，例如“本机房主 · 服务端延时 28ms · IPv6/UDP”或“与房主延时 42ms · IPv4/UDP”。
- 本机被服务端权威确认为房主时，启动器测试到固定服务端 `10.66.0.1` 的 TCP 服务延时，并读取 EasyTier 路径中的 IPv4/IPv6、UDP/TCP/WSS 信息。
- 加入其他玩家房间时，继续直接测试到房主虚拟 IP 的延时和路径；不会把普通客户端用作第三方中继。
- “检测网络”按钮移动到连接状态标题行，检测结果独占下一行，较长的房主路径文字不再被按钮挤压。
- 普通线上大厅显示“游戏已启动 · 等待房主信息”；配合 Server Tool v1.0.8，不再把单人个人会话误报为本机房主。

本版本不恢复客户端本地猜房主、广播转换或单播扇出，也不会在游戏运行期间重启 EasyTier、重建虚拟网卡或更换 `10.66.0.x` 地址。
