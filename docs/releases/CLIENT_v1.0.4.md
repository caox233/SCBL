# [CLIENT] Windows Client v1.0.4

## 修复内容

- 修复启动器偶发无法检查客户端版本、需要多次手动点击“重新检查”的问题。
- 客户端在显示失败弹窗前自动执行最多3次版本检查，每次都创建新的 HTTP 连接。
- 单次检查使用4秒连接超时和7秒总超时；重试间隔为350毫秒和900毫秒。
- 对连接超时、网络异常以及 HTTP 408、429、5xx状态执行自动重试；确定性的无效 manifest 不会被掩盖。
- 日志新增尝试次数、请求耗时、错误类型、内部异常摘要以及重试成功记录。
- 外部取消仍会立即生效，不会被内部重试吞掉。

## 版本边界

- Server Tool 继续保持 v1.0.3，服务端双栈更新脚本和 TCP 18080 配置不变。
- 启动顺序和强制版本确认规则不变；版本无法最终确认时仍只能重新检查或退出。
- EasyTier 网络策略、端口、Route Guard 路由逻辑、Hooks 和游戏文件均未修改。
