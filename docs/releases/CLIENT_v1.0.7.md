# [CLIENT] Windows Client v1.0.7

本版本根据四人联机诊断包修复控制平面偶发超时和在线玩家发现不完整问题。

## 主要修复

- 将心跳、在线列表、房间查询和启动信息拆分为独立 HTTP 连接池。
- 控制平面请求遇到超时、连接重置、HTTP 408、429 或 5xx 时，丢弃对应连接并自动重试一次。
- 心跳按固定5秒节拍发送，避免请求耗时不断推迟下一次心跳。
- 在线玩家列表同时合并服务器注册表、EasyTier 路由和 TCP 玩家探测结果。
- 兼容 EasyTier 2.6.x verbose JSON 的数值型 IPv4 地址，避免路由存在时仍扫描整个虚拟 `/24`。
- 修正多协议 peer 表导致的 WSS 路径误判，并放宽 verbose 路径查询时间。
- 修正游戏正常结束时 Route Guard 被记录为错误退出的日志误报。

## 保持不变

- 19080 仍是仅虚拟网访问的 SCBL 控制平面端口，不是旧更新端口。
- 公网客户端更新继续使用 TCP 18080。
- EasyTier、Hooks、WinDivert、游戏服务端、数据库结构和端口不变。
- 本版本不宣称解决游戏实时房主迁移；房主退出后的对局接管仍取决于游戏客户端协议行为。

## 升级

旧客户端启动后会通过现有完整包更新流程升级到 v1.0.7。完整 ZIP 和 SHA256 由 GitHub Actions 正式构建并发布。
