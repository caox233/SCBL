# [CLIENT] Windows Client v1.0.8

本版本修复 v1.0.7 链路类型显示回归，并针对开机后首次启动卡顿和游戏进入线上模式时的短暂网络抖动增加韧性处理。

## 主要修复

- 恢复服务端实际链路查询，状态栏可重新显示 UDP/WSS 与 IPv4/IPv6。
- Updater 和 WinDivert 启动检查移出 UI 线程，窗口保持响应并显示准备阶段。
- 游戏运行期间出现短暂服务器不可达时，先重试，再仅修复现有虚拟网卡路由绑定；不会自动重启 EasyTier 或改变当前虚拟 IP。
- 增加启动准备耗时及游戏内网络恢复日志。

## 说明

- 当前服务端入口配置为 UDP 与 WSS；WSS 基于 TCP/TLS，因此正常情况下显示 UDP 或 WSS，不保证出现独立的原始 TCP 标签。
- 本版本减少瞬时路径故障影响，但游戏自身的 PRUDP/线上登录状态机不会被启动器直接改写，因此不承诺完全消除所有“进入线上模式”卡住场景。
- Server Tool 继续保持 v1.0.4；EasyTier、Hooks、WinDivert 驱动内容、服务端数据库和端口均未改变。

## 升级

旧客户端通过现有完整包更新流程升级到 v1.0.8。正式 ZIP 与 SHA256 由 GitHub Actions 构建发布。
