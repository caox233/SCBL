# [SERVER] Server Tool v1.0.2

## 服务端调整

- 客户端更新服务同时监听 IPv4 和 IPv6，监听队列提升到 128，并禁止目录浏览。
- EasyTier 固定入口只发布 UDP 与 WSS；WSS 默认复用 11010/TCP。
- 玩家间 UDP/TCP 打洞保持启用，服务器继续作为唯一数据中继兜底。
- 控制平面监听队列提升到 128，增加连接超时保护，并把会话快照刷新周期调整为 2 秒。
- 安装和升级时自动迁移旧的 10443 WSS 默认端口。

## 数据保护

- 不修改、不覆盖 `server/5th-echelon.db`。
- 保留现有 DDNS-GO、客户端更新包、备份和服务配置。
- Hooks 源码和 DLL 未修改。
