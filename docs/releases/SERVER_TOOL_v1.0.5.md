# [SERVER] Server Tool v1.0.5

本版本修复控制平面进程仍显示运行、但19080长期不可用时，客户端无法获得权威房主和对局延迟的问题。

## 主要修复

- HTTP/1.1响应明确发送 `Connection: close`，每个请求结束后立即释放处理线程，不再等待8秒长连接空闲超时。
- 内置签名健康探针每15秒访问一次 `/v1/health`；连续两次完整请求失败时主动退出，由systemd自动重启。
- 控制平面服务改为 `Restart=always`，并设置 `TasksMax=128`、`MemoryHigh=192M`、`MemoryMax=256M`。
- 服务重启流程会等待 `10.66.0.1:19080` 实际监听；启动16毫秒就立即检查导致的假“未监听”不再出现。
- `scbl-server-status`正确识别绑定在 `0.0.0.0:50051` 或IPv6通配地址上的账号服务。
- 修复在线升级未把新控制平面同步到实际运行目录的问题；升级后重新执行一次 `SCBL`，首次启动迁移会自动部署并重启控制平面。

## 不变内容

- Windows Client仍为v1.0.9。
- dedicated_server、房间数据库、EasyTier、Hooks、WinDivert、端口与网络密钥均不变。
- 19080继续只绑定虚拟服务端地址，用于心跳、玩家列表和权威房间状态，不开放公网。

## 升级步骤

1. 在现有SCBL菜单选择“服务端工具在线升级”，升级到v1.0.5。
2. 退出当前菜单进程后重新执行 `SCBL` 一次；v1.0.5迁移会同步实际控制平面、更新systemd并等待19080就绪。
3. 执行 `scbl-server-status`，确认控制平面和账号服务均显示正常。

配置、账号数据库、客户端更新包和DDNS-GO配置都会保留。
