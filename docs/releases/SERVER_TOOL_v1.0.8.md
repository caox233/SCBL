# Server Tool v1.0.8

- 控制平面取消“任意单人未销毁会话即本机房主”的回退逻辑，避免玩家只进入普通线上大厅时误报房主。
- `/v1/game-session` 继续只使用游戏服务器数据库中的权威证据；房间状态要求至少两名参与者，并且至少存在两个不同的 `10.66.0.x` 注册地址。
- 已确认的多人会话仍会正确区分本机房主和其他玩家房主，并继续返回参与者数量供在线玩家面板和诊断使用。
- 不修改数据库结构、账号、密码、房间数据或 dedicated_server 二进制；Server Tool 在线升级仍保留配置、数据库、日志和菜单15诊断能力。

由于游戏服务器当前没有可区分“单人房间等待界面”和“普通线上大厅个人会话”的独立权威字段，单人等待阶段不会宣称已识别房主；第二名玩家进入后才显示权威房主状态。
